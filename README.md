# -cidadaniadigital2026

Este projeto é um portal de conscientização comunitária focado em ensinar cidadãos a identificarem mídias manipuladas por IA (Deepfakes) e alertar sobre os riscos de desinformação automatizada. Desenvolvido para a recuperação do Componente Curricular de Educação Digital e Computação.

## 🚀 Tecnologias Utilizadas
* HTML5 (Tags semânticas)
* CSS3 (Layout moderno com Flexbox e Media Queries)
* JavaScript Vanilla (Manipulação ativa do DOM e eventos)

## 🎯 Funcionalidades Básicas Integradas
* **Modo Escuro**: Recurso de acessibilidade que inverte dinamicamente as variáveis de cores do CSS via JavaScript.
* **Quiz Anti-Desinformação**: Um formulário interativo de validação em tempo real que calcula a pontuação do usuário e exibe feedbacks personalizados na tela sem recarregar a página.

## 🤖 Prompts de IA Utilizados no Processo de Desenvolvimento
1. *"Gere uma estrutura HTML5 semântica para um portal focado no combate a deepfakes contendo cabeçalho, seção de informações, formulário de quiz e rodapé."*
2. *"Crie regras CSS que utilizem variáveis de ambiente para simular um Dark Mode e estilize um layout flexível usando Flexbox."*
3. *"Escreva uma lógica JavaScript que capture o submit de um formulário de quiz, valide se o valor selecionado é correto, calcule o score e mude o texto de uma div de resultado no DOM."*
